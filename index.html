Paano i-install

  1. I-tap ang I-download ang APK gamit ang browser ng phone (hal. Chrome).
  2. Buksan ang na-download na file, mula sa notification o sa Downloads.
  3. Kapag tinanong, payagan ang Install unknown apps para sa browser o Files app.
  4. Kung may babala ang Play Protect, piliin ang Install anyway. Normal ito sa app na wala sa Play Store.
  5. Buksan ang Inpatient PF Tracker mula sa listahan ng apps.

PIN lock

  • Sa unang bukas, gagawa ka ng PIN (4–6 digits).
  • Ipapakita ang recovery code. Isulat ito sa papel at itago sa labas ng phone. Ito ang gagamitin kapag nakalimutan ang PIN.
  • Nagla-lock ang app kapag iniwan nang mahigit 1 minuto.

Bago mag-update

Kapag may bagong version, mag-Export backup muna sa loob ng app. Kung ayaw tanggapin ng phone ang update, i-uninstall ang luma, i-install ang bago, tapos i-Import backup.

Tungkol sa data

  • Gumagana ang app nang walang internet. Wala itong cloud o sync.
  • Sa phone lang naka-save ang records. Mabubura ang mga ito kapag in-uninstall ang app.
  • Hindi naka-encrypt ang backup file. Itago ito nang maayos at huwag ipadala sa hindi secure na apps.
