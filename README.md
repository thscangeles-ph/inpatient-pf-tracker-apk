# Inpatient PF Tracker: Android installer

APK lang ang nandito (walang source code at walang patient data).

## I-download
**[InpatientPFTracker-v1.3.apk](https://github.com/thscangeles-ph/inpatient-pf-tracker-apk/releases/latest/download/InpatientPFTracker.apk)**

## I-install
1. I-download ang APK gamit ang browser ng phone (Android 8.0 o mas bago).
2. Buksan ang file at payagan ang **Install unknown apps** kapag tinanong.
3. Kung may babala ang Play Protect, piliin ang **Install anyway**.

## Paalala
- Offline ang app at sa phone lang naka-save ang records.
- Mag-**Export backup** muna bago mag-install ng bagong version.
